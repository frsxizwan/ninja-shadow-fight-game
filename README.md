A cinematic 2D mobile action fighting game built in Unity, inspired by the fast-paced combat of Katana Zero and the cinematic silhouette style of Shadow Fight.

This project is a fully playable Unity prototype featuring responsive combat mechanics, modular weapon systems, AI-driven enemies, boss battles, and a mobile-optimized control system designed for Android and iOS deployment.

---

## 🎮 GAME OVERVIEW

Shadow Zero: Katana Protocol is a fast, stylized 2D side-scrolling combat game where precision, timing, and skill define survival. Players engage in high-intensity ninja combat against AI-controlled enemies and powerful boss units using melee weapons, ranged tools, and elemental abilities.

The game emphasizes **combat feel**, **responsiveness**, and **cinematic presentation** over complexity, delivering a polished arcade-style experience optimized for mobile platforms.

---

## ⚔️ CORE FEATURES

### 🥷 Fluid Combat System
- Responsive input buffering system for smooth attacks
- 3-hit light combo chain system with timing windows
- Heavy attacks with knockback and impact scaling
- Block and counter mechanics
- Hit-stop effect for impactful combat feedback

### 🔥 Weapon System
- Katana (balanced melee combat)
- Dual Swords (fast combo-focused attacks)
- Kunai (ranged projectile system)
- Fire Blade (elemental area damage abilities)

Each weapon features:
- Unique attack speed and damage scaling
- Custom animations and visual effects
- Distinct combat feel and timing

### 🧠 Enemy AI System
- State-based AI (Idle, Patrol, Chase, Attack, Retreat)

- Adaptive aggression based on player behavior

## 🏗️ TECHNICAL ARCHITECTURE

This project is built using modular Unity systems for scalability and performance:

- `PlayerController.cs` → Movement & animation control  
- `CombatSystem.cs` → Attack logic, combos, hit detection  
- `WeaponManager.cs` → Weapon switching & configuration  
- `SkillSystem.cs` → Fire abilities & cooldown logic  
- `EnemyAI.cs` → State machine enemy behavior  
- `BossAI.cs` → Multi-phase boss system  
- `HealthSystem.cs` → Damage & health management  
- `GameManager.cs` → Game state control (win/lose/progression)  
- `CameraSystem.cs` → Cinematic camera behavior  
- `EffectManager.cs` → Screen shake, hit-stop, visual FX  
- `UpgradeSystem.cs` → Player progression system  
- `MobileInputHandler.cs` → Touch control system
